# BoFire Lab Portal — 同事使用手册

> 给你:有机化学实验室研究员
> 工具:无代码贝叶斯优化 — 用 Excel 配因子,Python 自动推荐下一组实验条件。
> **状态**: ✅ 真 GP-BO 已验证(1728 条真实反应 + 5 轮 demo)

## 一句话看懂

```
你在 Excel 填因子 + 实验结果
    ↓
Python 自动算出下一组该做什么条件
    ↓
你照着做,做完填回去,再下一组
```

GP-BO(高斯过程 + 贝叶斯优化)是个统计学方法,5 轮左右就能找到比纯随机 / 网格搜索好得多的条件。我们已经验证过,在 1728 条真实 Pd-催化反应里,5 轮 GP-BO 找到了高产组合(KOAc+CgMe-PPh+DMAc)。

## 5 分钟试用 — Suzuki demo

> 这个 demo 已经预填了 6 条 Suzuki 反应数据,你跟着走一遍就知道怎么用。

### 步骤

1. 打开 `D:\BOFIRELabPortal\projects\Suzuki_2026Q4_demo\Suzuki_2026Q4_demo.xlsx`
2. 默认落在 `🚀 开始` sheet,顶部显示"步骤 1/4 · 待配置"
3. 切到 `⚙️ 配置` sheet — 模板已经填好示例(温度 / 催化剂用量 / 反应时间 / 溶剂 / Yield)
4. 切到 `🧪 记录` sheet — 看 6 行初始数据(其中 1 条 valid=0 是"失败")
5. 切回 `🚀 开始` sheet,点 `[🚀 启动 BO]`(或双击 `跑_BO_点这里.bat`)
6. 等 30-60 秒,屏幕右下角弹"✅ BO 已完成"
7. 切到 `📊 看板` sheet — 看到本轮推荐 3 组新条件
8. 去实验室做这 3 组反应,测 Yield
9. 把 📊 看板 顶部的推荐条件**复制**到 🧪 记录 sheet
10. 在 Yield 列填实测值,**Ctrl+S 保存**
11. 重复点 [🚀 启动 BO],进入下一轮

**完整流程演示一遍,你就可以开始自己的项目了。**

## 3 分钟开始自己的项目

新建项目流程:

1. 复制 `templates\project_template.xlsx`
2. 改名为 `projects\<项目名>_<你的姓名>.xlsx`
3. 打开,跟着 `🚀 开始` sheet 的引导:
   - 填 ⚙️ 配置(因子 + 目标 + 策略)
   - 填 🧪 记录(你已经做过的实验结果)
   - 点 [🚀 启动 BO] → 看 📊 看板 推荐
4. 去实验室做,测 Yield
6. 填回 🧪 记录,Ctrl+S
7. 点 [🚀 启动 BO] → 下一轮

> **建议**: 启动 BO 前,在 🧪 记录 sheet 顶部手动填 3-5 条你已经知道的"还行"的条件,让 GP 学得快一点。

## Sheet 角色一览(关键)

| Sheet | 你的角色 |
|-------|---------|
| `🚀 开始` | 看状态、点按钮、读下一步提示 |
| `⚙️ 配置` | 你编辑 — 填因子 / 目标 / 策略 |
| `🧪 记录` | 你编辑 — 填实验条件 + 实测 Yield |
| `📊 看板` | 系统写,你只读 — 推荐 / 曲线 / 日志 |

**不要修改 `📊 看板` sheet**!系统每轮都会重写,你的修改会被覆盖。

### ⚙️ 配置 表怎么填

| 列 | 填什么 | 例子 |
|---|------|------|
| key | 因子名(中英文都行) | 温度、催化剂用量 |
| type | continuous(连续)/ categorical(分类) | continuous |
| trainable | TRUE / FALSE — FALSE 表示这个因子固定(比如固定溶剂) | TRUE |
| low / high | continuous 必填 | 20 / 100 |
| categories | categorical 必填,用 `;` 分隔 | 甲苯;THF;DMF |
| unit | 单位(可选) | °C, mol%, h |

> 不知道类型时,**先全部填 continuous + low/high**,最简单。

## 出现意外怎么办

| 现象 | 怎么办 |
|------|--------|
| **BO 没反应** | 看 `projects\<项目>\LOG.txt` 最后报错信息,转给 IT |
| **📊 看板 不动** | 点 `[🔄 刷新最新推荐]` 按钮 |
| **config 改坏了** | 看 `🚀 开始` sheet 的红色提示,改对应格子 |
| **Excel 弹黄条"外部修改"** | **选"加载磁盘版本"** — Python 写的推荐不会丢 |
| **完全卡住 / 出错弹窗** | 双击 `projects\<项目>\跑_BO_点这里.bat`,cmd 窗口会显示详细日志 |
| **看不懂推荐条件** | 看 📊 看板 的"本轮推荐"区,有 GP 预测的 mean / sd(仅供参考) |
| **做了一轮后想重置** | 删除 `.cache/` 目录,重跑 [🚀 启动 BO] |
