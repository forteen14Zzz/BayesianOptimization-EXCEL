# BoFire Lab Portal — 同事使用手册

> 给你:有机化学实验室研究员
> 工具:无代码贝叶斯优化 — 用 Excel 配因子,Python 自动推荐下一组实验条件。

---

## 安装(一次性,IT 帮你装)

1. IT 在 `D:\BOFIRELabPortal\` 解压安装包
2. 双击 `install\install.bat`
3. 等 5-10 分钟(装 BoFire 等 Python 包)
4. IT 配好开机启动项 — 以后你**不用再碰任何东西**

---

## 测试一遍

1. 打开 `D:\BOFIRELabPortal\projects\Suzuki_2026Q4_demo\Suzuki_2026Q4_demo.xlsx`
2. 默认落在 `🚀 开始` sheet — 看上面会显示"步骤 1/4, 待配置"
3. 切到 `⚙️ 配置` sheet,填几个因子和目标(模板已经填好示例)
4. 切到 `🧪 记录` sheet,看初始 5 条数据
5. 切回 `🚀 开始` sheet,点 `[🚀 启动 BO]`
6. 等 30-60 秒,弹通知 "✅ BO 已完成"
7. 切到 `📊 看板` sheet — 看到本轮推荐 3 组新条件
8. 去实验室做这 3 组实验,测 Yield
9. 复制 `📊 看板` 顶部的推荐条件到 `🧪 记录` sheet
10. 填实测 Yield,Ctrl+S 保存
11. 点 `[🚀 启动 BO]` — 进入下一轮

**完整流程演示一遍,你就可以开始自己的项目了。**

## 测试二遍

新建项目流程:
1. 复制 `templates\project_template.xlsx`
2. 改名为 `projects\你的项目<项目名>.xlsx`
3. 打开,跟着 `🚀 开始` sheet 的引导走

## 状态表位置(关键)

| Sheet | 你的角色 |
|-------|---------|
| `🚀 开始` | 看状态,点按钮 |
| `⚙️ 配置` | 你编辑 — 填因子 / 目标 / 策略 |
| `🧪 记录` | 你编辑 — 填实验条件 + 实测值 |
| `📊 看板` | 系统写,你只读 — 推荐 / 曲线 / 日志 |

**不要修改 `📊 看板` sheet**!系统每轮都会重写。

## 出现意外怎么办

| 现象 | 怎么办 |
|------|--------|
| "BO 没反应" | 看 `projects\<项目>\LOG.txt` 最后报错信息,转给 IT |
| "📊 看板 不动" | 点 `[🔄 刷新最新推荐]` 按钮 |
| "config 改坏了" | 看 `🚀 开始` sheet 的红色提示,改对应格子 |
| "Excel 弹黄条说外部修改" | **选"加载磁盘版本"** — Python 写的推荐不会丢 |
| "完全卡住 / 出错弹窗" | 双击 `projects\<项目>\跑_BO_点这里.bat`,cmd 窗口会显示详细日志 |
